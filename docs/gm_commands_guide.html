Gamemaster Commands & Spells Reference

Complete technical guide for Tibia 7.7x Unified Server Gamemaster and GOD spells, moderation actions, and system permissions.

1. Movement & Teleportation Spells

Spell / Incantation Function Syntax & Parameters Required Permission Practical Example Description & Behavior
alani "up" / "down" Vertical Floor Teleport alani "<up|down>" TELEPORT_VERTICAL alani "up" Teleports the Gamemaster 1 floor up or down instantly. Does not require stairs, ladders, or holes.
alani "x,y,z" Coordinate Teleport alani "<x,y,z>" TELEPORT_TO_COORDINATE alani "1000,1000,7" Teleports the Gamemaster directly to the specified map coordinates. Supports "x,y,z" or "[x,y,z]".
alani "N" Step Teleport alani "<steps>" TELEPORT_TO_COORDINATE alani "5" Teleports the Gamemaster N tiles forward in the direction they are currently facing. Can cross impassable borders if destination is clear.
alani "MarkName" Teleport to Map Mark alani "<mark_name>" TELEPORT_TO_MARK alani "thais" Teleports the Gamemaster to a predefined map position / town mark by name.
alani "speed" Set Walking Speed alani "<fast|fastest|normal|slow>" MODIFY_GOSTRENGTH alani "fastest" Changes the Gamemaster's movement speed. Options: fast (speed +100), fastest (speed +200), or normal / slow (reset to default).
alani sio "Player" Teleport to Player (/goto) alani sio "<character_name>" TELEPORT_TO_CHARACTER alani sio "Bubble" Teleports the Gamemaster directly to the current location of the target player.
alliber sio "Player" Retrieve Player (/bring) alliber sio "<character_name>" RETRIEVE alliber sio "Bubble" Pulls/teleports the target player from anywhere in the world to the Gamemaster's current position.
omani "Player" Temple Teleport (/home) omani "<character_name>" HOME_TELEPORT omani "Bubble" Teleports the target player immediately to the temple of their hometown (start position).
alani hur "up" / "down" Levitate Gamemaster alani hur "<up|down>" LEVITATE alani hur "up" Levitates the Gamemaster up or down without mana cost or elevation restrictions.
aliva tera Get Current Position (GPS) aliva tera SHOW_COORDINATE aliva tera Prints the Gamemaster's current position ([X, Y, Z]) in the chat window.

2. Creation & Spawning Spells

Spell / Incantation Function Syntax & Parameters Required Permission Practical Example Description & Behavior
alevo "Item", Count Create Items (/i) alevo "<item_name|id>", <1-100> CREATE_OBJECTS alevo "magic sword", 1
alevo crystal coin, 100		 Creates 1 to 100 units of an item by name or ObjectType ID in the player's hands or on the ground. Quotes are optional for single/multi-word item names.
alevo vis "Amount" Create Money / Gold alevo vis "<1-1000000>" CREATE_MONEY alevo vis "50000" Creates a specific amount of gold (1 to 1,000,000), automatically converting and splitting into Crystal Coins (10k), Platinum Coins (100), and Gold Coins (1).
alevo res "Monster" Summon Wild Monster (/m) alevo res "<race_name>" CREATE_MONSTERS alevo res "Demon"
alevo res "Dragon Lord"		 Spawns a free/wild monster by name with no mana cost, no level check, and ignoring the standard 2-summon limit.
alevo mas res "Raid" Trigger Monster Raid (/raid) alevo mas res "<raid_name>" CREATE_MONSTERS alevo mas res "rats_thais" Manually starts a monster raid event defined in the server's .evt monster files.

3. Character, Vocation, Skills & Quests

Spell / Incantation Function Syntax & Parameters Required Permission Practical Example Description & Behavior
aleta vita "Option" Change Vocation or Sex aleta vita "<voc|sex>" CHANGE_PROFESSION aleta vita "knight"
aleta vita "male"		 Changes character vocation (knight, paladin, sorcerer, druid, promotion, none) or gender (male, female).
alevo cogni "Exp" Add Level Experience alevo cogni "<exp_points>" CHANGE_SKILLS alevo cogni "100000" Directly adds experience points to the character's general experience, advancing level accordingly.
alevo cogni "Skill" "Exp" Add Skill Experience alevo cogni "<skill_id>" "<exp>" CHANGE_SKILLS alevo cogni "8" "50000" Adds skill points to a specific skill (Skill 1=Magic, 6=Shield, 7=Dist, 8=Sword, 9=Club, 10=Axe, 11=Fist, 13=Fish).
aleta "Value" Modify Item Attributes aleta "<numeric_value>" CREATE_OBJECTS aleta "50"
aleta "3001"		 Modifies held item or door in front: sets rune charges (1-99), stackable item count (1-100), key number, or door keyhole lock ID.
aliva cogni "QuestID" Get Quest / Storage Value aliva cogni "<quest_number>" CHANGE_SKILLS aliva cogni "100" Queries and displays the current storage value of the specified quest ID in the chat window.
aleta cogni "Quest" "Val" Set Quest / Storage Value aleta cogni "<quest_id>" "<val>" CHANGE_SKILLS aleta cogni "100" "1" Sets a specific quest/storage state on the character (e.g. marking a quest complete or advancing stage).
alana cogni Clear All Quest Values alana cogni CHANGE_SKILLS alana cogni Resets and clears all quest/storage numbers on the character back to zero.

4. Moderation & Punishment Spells

Spell / Incantation Function Syntax & Parameters Required Permission Practical Example Description & Behavior
omana "Player" Kick Player (/kick) omana "<character_name>" KICK omana "Troll" Disconnects and kicks the target player from the game server immediately with green magic visual effect.
omana res "Name" "Days" "Reason" Banish Character (/ban) omana res "<name>" "<days>" "<reason>" BANISHMENT omana res "Troll" "7" "Insults" Banishes a character for a specified duration of days with an entry logged to the database. (In 7.7x clients, Ctrl+Y can also be used).
omana liber "Acc" "Days" "Reason" Banish Account omana liber "<acc_id>" "<days>" "<reason>" BANISHMENT omana liber "123456" "30" "Bot" Banishes the entire account. Prevents all characters on that account from logging in during the ban period.
omana vis "IP/Player" "Reason" IP Banishment omana vis "<ip|name>" "<reason>" IP_BANISHMENT omana vis "192.168.1.1" "Spam" Blocks connections from the target IP address or from the specified online player's current IP.
omana hora "Player" Namelock Character omana hora "<character_name>" NAMELOCK omana hora "BadName" Locks the character name due to rule violation, forcing the player to rename the character before entering the game.
omisa "Player" "Comment" Criminal Record Notation omisa "<character_name>" "<comment>" NOTATION omisa "Player" "Warning for spam" Adds a formal written notation/warning to the character's criminal record without banishment.

7. System IDs & Permissions Reference

Skill IDs (for alevo cogni)

  • 0 - Level Experience (General EXP)
  • 1 - Magic Level (Mana spent)
  • 6 - Shielding (Shield Defense)
  • 7 - Distance Fighting (Bows & Crossbows)
  • 8 - Sword Fighting
  • 9 - Club Fighting
  • 10 - Axe Fighting
  • 11 - Fist Fighting
  • 13 - Fishing

Key Character Rights (Flags)

  • INVULNERABLE - Complete damage and death immunity.
  • UNLIMITED_MANA - Spells cost 0 mana.
  • UNLIMITED_CAPACITY - Infinite carrying capacity.
  • ALL_SPELLS - Access to all spells regardless of vocation.
  • ENTER_HOUSES - Access to any house without invitation.
  • OPEN_NAMEDOORS - Opens level/quest doors freely.
  • GAMEMASTER_OUTFIT - Grants the blue Gamemaster outfit.
  • ATTACK_EVERYWHERE - Attack inside Protection Zones.

Special Communication Modes

  • Ctrl + Y - Official in-game Rule Violation report dialog for handling player complaints and applying bans/namelocks.
  • #b <Message> - Red Gamemaster broadcast displayed in the center of the screen to all online players.
  • Gamemaster Channel - Private channel for GM/GOD staff communication.
  • Help Channel - Highlighted tutor/GM responses in orange text.
