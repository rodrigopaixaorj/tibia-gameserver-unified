📜 Quick Start: How the System Works

Easy 2-Step Workflow
⚔️

Broadcasting Your Stream

  1. Enable Live Broadcast:
    Say !cast on or /cast on in default or game chat. The server will notify: "Live Cast is now ONLINE."
  2. Set Title / Description:
    Say !cast desc Demon Hunt at Edron to display your activity to everyone browsing the stream list.
  3. Protect with Password (Optional):
    Say !cast password secret123 to restrict access. Broadcasts with passwords are shown with an asterisk (*).
  4. Monitor Your Viewers:
    Say !cast viewers to see who is watching in real time. Turn off anytime with !cast off.
👁️

Watching a Live Stream

  1. Launch Tibia 7.72 Client:
    Open your regular Tibia client connected to the server IP and port 7171.
  2. Enter Account "0":
    In the Account Number field, type 0. If the stream is public, leave the Password field blank. If password-protected, type the stream's password.
  3. Pick a Streamer:
    A character list will appear containing all active broadcasters, e.g.: Shadow Spinal (Cast [3/25]). Click Ok to enter!
  4. Seamless Zapping:
    Use Ctrl + ↑ and Ctrl + ↓ while watching to switch instantly to another broadcaster!
💡
Did You Know? The native Live Cast system replicates packets at the game server network layer before encryption. Broadcasting players experience zero latency impact and spectators do not expose the player's account data.

👁️ Spectator Controls & Security Safeguards

Built-in Anti-Abuse Protection
🔁

Stream Zapping (Ctrl + Arrow Keys)

Spectators can seamlessly flip channels using Ctrl + ↑ and Ctrl + ↓ keys. The server re-synchronizes the spectator to the new streamer's viewport in real time.

🛡️

Command Injection Guard

All spectator game packets are strictly intercepted by CommandAllowed. Spectators cannot move characters, drop items, cast spells, or use runes.

💬

Spectator Console Chat

Spectators can talk with each other and interact with the broadcaster. Chat messages appear exclusively in the console window (never obscuring gameplay on screen) and are cleanly formatted.

🔒

Account & Password Isolation

Spectators connect via Account 0. The broadcaster's real Account Number, Password, Recovery Key, and IP address are never exposed to viewers.

⚙️ Server Configuration (`config.cfg`)

Native Config Parameters

You can configure the Live Cast system settings inside the server's root configuration file: config.cfg.

# ==============================================================================
# Native Live Cast System Configuration (CipSoft 7.72 Engine)
# ==============================================================================
live_cast_enabled = true # Master switch: true to enable live broadcasts, false to disable
live_cast_max_spectators = 25 # Maximum concurrent spectators allowed per individual stream
world_address = "127.0.0.1" # Public IP or domain sent to spectators during character selection
game_port = 7172 # Game server port (Spectators connect to 7171 for list, 7172 for stream)
Parameter Default Accepted Values Description
live_cast_enabled true true / false Enables or disables the entire live cast broadcast engine globally.
live_cast_max_spectators 25 1 to 100 Limits spectators per streamer to guarantee optimal bandwidth distribution.
world_address "127.0.0.1" IPv4 or Domain Server address given to spectators. Use your public IP or WAN domain for live servers.

❓ Frequently Asked Questions & Troubleshooting

Common Solutions
How do I watch streams protected by a password? ▾
When logging in with Account Number 0, simply enter the streamer's cast password in the Password field in the Tibia client. The server will authenticate the password and list only the streams authorized for that key.
What should I do if I get "Error: Invalid server address"? ▾
Ensure that world_address in config.cfg is configured with your machine's IP address (e.g., 127.0.0.1 for local play or your public IPv4 for external players). In the latest server build, this is automatically resolved to prevent zero-address responses.
Does broadcasting create server lag or drop FPS for players? ▾
No. The CipSoft unified engine replicates packets in raw memory prior to XTEA encryption, streaming chunks directly through dedicated socket buffers. Broadcasting has zero impact on monster AI, combat ticks, or player movement latency.
What ports need to be forwarded for external spectators? ▾
Standard Tibia ports 7171 (Login Server) and 7172 (Game Server). Spectators query 7171 to receive the active streamer list, then connect directly to 7172 to spectate gameplay.
